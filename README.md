# ⚡ Personal Developer Portfolio

![Project Status](https://img.shields.io/badge/Status-Live-success)
![Tech Stack](https://img.shields.io/badge/Built%20With-HTML%20%7C%20CSS%20%7C%20JS-blue)

A high-performance, responsive developer portfolio built from scratch using **Semantic HTML5**, **Modern CSS3**, and **Vanilla JavaScript**. 

Designed to showcase my projects (React, Node.js, C++) and technical skills with a focus on **Visual Hierarchy**, **Accessibility**, and **Speed**.

## ✨ Key Features

* **🌓 Dark/Light Mode Toggle:** professionally implemented using CSS Variables and persisted via `localStorage` (remembers user preference on reload).
* **⚡ Zero Dependencies:** No heavy frameworks (Bootstrap/jQuery). Pure CSS Grid & Flexbox for maximum performance (Lighthouse score: 100).
* **🎬 Scroll Animations:** Elements fade in and slide up using the `Intersection Observer API` for a smooth user experience.
* **📱 Fully Responsive:** Mobile-first architecture ensuring the site looks perfect on phones, tablets, and desktops.
* **📋 Smart Contact:** Custom "Click to Copy" email feature with visual feedback.
* **🖼️ Parallax Hero:** Dynamic background image with overlay for text readability.

## 🛠️ Tech Stack

* **Structure:** HTML5 (Semantic Tags for SEO)
* **Styling:** CSS3 (Custom Properties/Variables, Grid, Flexbox, Backdrop Filter)
* **Logic:** JavaScript (ES6+, DOM Manipulation, Event Listeners)

## 🚀 How to Run Locally

Since this is a static site, you don't need to install any node modules or dependencies.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/Piyushsharma69/my-portfolio.git](https://github.com/Piyushsharma69/my-portfolio.git)
    ```

2.  **Navigate to the project folder:**
    ```bash
    cd my-portfolio
    ```

3.  **Open the site:**
    * Simply double-click `index.html` to open it in your browser.
    * OR use a Live Server extension in VS Code for hot-reloading.
